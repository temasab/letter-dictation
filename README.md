# Буквенный диктант

Тренажёр для первоклассника: голос называет буквы (русские или английские) в случайном порядке,
ребёнок пишет их в тетради, затем вместе проверяем — буквы показываются прописью (заглавная и строчная)
и озвучиваются ещё раз.

Сайт: https://temasab.github.io/letter-dictation/

Статический сайт без сборки и без сервера: HTML + CSS + JavaScript. Озвучка — заранее записанные
mp3-файлы (папка `audio/`), воспроизводятся через Web Audio с плавным затуханием, поэтому без щелчков
и одинаково на всех устройствах. Если файл недоступен (или в настройках выбран «Голос браузера»),
используется встроенный синтезатор речи (Web Speech API). История диктантов — `localStorage` браузера.

## Возможности

- Выбор алфавита: русский или английский.
- Выбор диапазона касаниями прямо по алфавиту (первая и последняя буква), отдельный режим «Исключить».
- Диктант: буквы в разнобой, настраиваемая пауза, повтор каждой буквы дважды, пауза/повтор/прерывание.
- Тренировка: как диктант, но после паузы на письмо сразу показывается правильная буква на разлиновке
  (время показа — в настройках, кнопка «Дальше →» переходит раньше).
- Ограничение количества букв (в настройках): из выбранных берётся заданное число случайных букв без повторов.
- Регистр (в настройках): не называть, все заглавные, все строчные или вперемешку — голос говорит
  «заглавная бэ», на проверке продиктованная форма выделена.
- Проверка: все буквы диктанта сеткой + по очереди крупная буква на разлиновке прописи с озвучкой;
  нажатие на любую букву — услышать её снова.
- Сохранённые занятия (диктанты и тренировки с метками): повторить, перемешать заново, сразу открыть
  проверку, поделиться, удалить.
- Поделиться диктантом: ссылка или код с буквами в их порядке, регистром, названием и настройками
  диктанта (паузы, повтор). Открыть — по ссылке или кнопкой «Открыть по коду». Формат кода — `js/share.js`.
- Настройки (кнопка ⚙ справа вверху, окно с закладками «Диктант», «Проверка», «Голос», «Пропись»): записанный голос или голос браузера, шрифт прописи и др.

## Запуск локально

Запустите простой сервер (при открытии `index.html` двойным щелчком браузер не даст загрузить
аудиофайлы, и сайт перейдёт на голос браузера):

```sh
python3 -m http.server 8000
# затем http://localhost:8000
```

## Публикация на GitHub Pages

Сайт публикуется автоматически workflow `.github/workflows/pages.yml` при каждом `git push` в ветку
`main` (в настройках репозитория: Settings → Pages → Source: GitHub Actions). Ход публикации — во
вкладке Actions репозитория; через 1–2 минуты после успешного запуска изменения видны на сайте.

## Структура

```
index.html        разметка трёх экранов: настройка, диктант, проверка
css/style.css     стили и подключение шрифтов
js/letters.js     алфавиты, произношение букв, шрифты-прописи
js/speech.js      обёртка над синтезатором речи
js/storage.js     настройки и история в localStorage
js/share.js       код диктанта для «Поделиться» (base64url от короткого JSON)
js/app.js         логика экранов и последовательного озвучивания
fonts/            шрифты-прописи (woff2) и их лицензии
audio/ru/         названия русских букв: 00.mp3 (А) … 32.mp3 (Я), а также
                  upper.mp3 («заглавная»), lower.mp3 («строчная»), start.mp3, end.mp3,
                  train-start.mp3 («Начинаем тренировку!»)
audio/en/         названия английских букв: a.mp3 … z.mp3
```

## Аудиозаписи

Сгенерированы синтезатором речи Eleven v4 через Runway (ноябрь 2026): русские буквы — голос
«Alisa — Natural Russian Female», английские — британский голос «Paula». Каждая буква записана
отдельным запросом. Английские буквы записаны по их английским названиям, переданным словами
(Ey, Bee, See, Dee, Ee, Eff, Gee, Aitch, Eye, Jay, Kay, Ell, Em, En, Oh, Pee, Queue, Are, Ess, Tea,
You, Vee, Double you, Ex, Why, Zed): одиночную латинскую букву синтезатор читает «по‑континентальному»
(A как «а», B как «бэ»). Чтобы заменить запись, положите новый mp3 с тем же именем — громкость
выравнивается автоматически при воспроизведении.

## Шрифты

Все шрифты распространяются под [SIL Open Font License 1.1](fonts/OFL-marckscript.txt):

- [Andika](https://fonts.google.com/specimen/Andika) — печатные заглавные русские буквы (в паре с Marck Script);
- [Marck Script](https://fonts.google.com/specimen/Marck+Script) — русская пропись (по умолчанию);
- [Bad Script](https://fonts.google.com/specimen/Bad+Script) — русский аккуратный почерк;
- [Playwrite US Trad](https://fonts.google.com/specimen/Playwrite+US+Trad) — английская пропись с петлями (по умолчанию);
- [Playwrite GB S](https://fonts.google.com/specimen/Playwrite+GB+S) — английская полупечатная и печатные заглавные.

По умолчанию буквы показываются обычным шрифтом — системным Arial (или похожим шрифтом устройства), он не скачивается.

Размер шрифта на экране проверки (`size` в `js/letters.js`) подобран так, чтобы строчная буква
занимала рабочую строку разлиновки.
